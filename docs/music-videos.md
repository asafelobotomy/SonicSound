# Music videos (YouTube)

Music-video / YouTube integration is **deferred**.

## Policy

If this is ever implemented, SonicSound will use only:

- The [official YouTube Data API](https://developers.google.com/youtube/v3)
- The official YouTube IFrame Player API

## Out of scope

Do **not** add:

- HTML scrapers or unofficial search proxies
- DuckDuckGo / Bing HTML scraping for video links
- NewPipe, Invidious clients, or similar unofficial extractors
- Any approach that violates YouTube Terms of Service

Until an official API key and product decision exist, keep playback focused on Subsonic/Navidrome library streaming and internet radio stations.
